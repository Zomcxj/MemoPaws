# 用户指南

## 功能

MemoPaws 提供以下功能：

- **备忘录**：Markdown 笔记、搜索、渲染、本地持久化和数据迁移
- **密钥管理**：加密密钥库、主密码锁定/解锁、增删改查、排序
- **剪贴板历史**：文本与图片记录、搜索、锁定、批量删除，重复内容自动去重置顶
- **AI 识别与翻译**：截图、OCR、图像预处理（灰度/二值化/整图马赛克）、裁剪、翻译和操作历史
- **文字替换**：Windows 全局键盘钩子驱动的缩写替换
- **快捷键与托盘**：可配置的全局快捷键、系统托盘和关闭行为

## 全局快捷键

| 动作 | 默认快捷键 | 说明 |
|---|---|---|
| `capture` | `Alt+X` | 从任意页面直达屏幕截图（托盘隐藏时同样有效） |
| `canvas_fit` | `Ctrl+F` | 画布自适应缩放 |
| `new_memo` | `Ctrl+N` | 新建备忘录 |
| `global_search` | `Ctrl+Shift+F` | 打开全局搜索 |
| `toggle_clipboard` | `Ctrl+Shift+V` | 切换剪贴板历史 |

所有快捷键都可以在设置页面中修改。

## 截图保存与钉图

- 框选后可调整圆角；确认、复制、保存和钉图使用相同的圆角 PNG，四角保留透明像素。
- 框选后可先标注再导出：操作条第一行提供移动、箭头、矩形、画笔、文字、马赛克六种工具，可调颜色与线宽，支持撤销/重做。箭头/矩形/马赛克拖一次画一笔，画笔按轨迹绘制；文字工具点击选区落点后输入，Enter 换行，Ctrl+Enter（或"提交文字"按钮）提交一笔文字标注，Esc 或"取消文字"只丢弃当前文字草稿。
- 标注保存在原图像素上，预览与确认、复制、保存、钉图的导出字节来自同一合成器——所见即所得；马赛克按 4×线宽 的方块对已绘制像素做块平均，可能盖住先画的标注（属预期行为）。
- 识别、翻译或保存进行中仍可继续标注或重新框选；新的绘制会作废尚未返回的旧识别结果，不会误填。
- 选区操作条、识别页工具栏和图片右键菜单的“保存图片”均打开系统“另存为”对话框，选择路径后保存 PNG；取消不会写入文件。
- 保存框以截图窗口为所有者模态弹出，始终显示在浮层之上、立即可见可操作；保存成功、取消或失败后都恢复原选区，无需先退出截图。
- 保存期间按钮显示忙碌状态；如果保存失败，截图浮层内显示错误提示，可重试。
- 截图通过二进制传输到界面，选区裁剪在本地画布完成，避免每次保存、识别或钉图重复传输和解码整张屏幕，进入截图和钉图更快。
- 支持多张独立钉图：每次钉图生成独立置顶窗口，互不覆盖；左键拖动位置，滚轮等比缩放（保持图片比例与透明圆角），×、右键或 Esc 只关闭当前钉图。
- 钉图期间主窗口保持隐藏，仍可用截图快捷键继续新增钉图；关闭最后一张钉图后，按第一张钉图截图前主窗口的可见状态恢复（原本可见才恢复显示，原本隐藏则保持隐藏）。

## 数据存储

应用数据默认存储在 `%USERPROFILE%/.memopaws/`，包含：

| 路径 | 内容 |
|---|---|
| `memo/` | 备忘录文件 |
| `keys.json` | 加密密钥库 |
| `clipboard.json` | 剪贴板历史 |
| `setting.json` | 应用配置 |
| `clipboard_images/` | 剪贴板图片 |
| `captures/` | 截图文件 |

数据目录可以在设置中迁移，支持 Merge 和 Replace 两种模式。
旧版 `.memopaws-rust` 数据不会自动迁移；如需保留，请在设置页手动选择该目录并使用 Merge 或 Replace。

## 自动更新

应用启动后每 15 秒与之后每小时自动比对 GitHub Releases 的最新版本。发现新版本时，侧边栏“设置”入口出现红点，设置页顶部显示“发现新版本”卡片并标明新旧版本号。

在卡片中可选择：
- **下载安装包**（`MemoPaws_<版本>_x64-setup.exe`）：下载后应用将自动关闭并完成静默安装，安装完成后请手动重新打开 MemoPaws
- **下载离线包**（`MemoPaws_<版本>_x64.exe`）：下载完成后应用内出现“重启以完成更新”按钮，点击后替换程序文件并重启应用

网络请求先直连 GitHub，失败后自动改走系统代理；检查失败不会打扰你，下一小时会重试。

## 配置

配置文件为数据目录下的 `setting.json`，常用字段如下：

- `theme`：主题，支持 `dark`、`light` 和 `auto`（跟随系统）
- `language`：界面语言
- `close_behavior`：关闭行为，支持 `exit` 和 `tray`
- `api_url`、`api_model`：AI 服务地址与模型（默认模型 `glm-4v-flash`）
- `shortcuts`：快捷键覆盖
- `text_replacements`：文字替换规则
- `clipboard_max_items`：剪贴板历史记录上限
- `history_max_items`：操作历史记录上限

API Key 通过应用内的密钥管理页面保存（存入加密密钥库 `keys.json`，不写入 `setting.json`）。
